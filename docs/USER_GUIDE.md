# User Guide — Employee Kanban

## Opening the board

Go to: https://hermesagenttabbeqai.github.io/employee-kanban/

The board loads with three columns: **TODO**, **In-Progress**, and **Ready**.

## Adding a task

1. Click the **Add Task** button at the top of the page.
2. Enter a task title (required).
3. Optionally add a short description (up to 200 characters).
4. Select the employee responsible from the dropdown: John Doe, Elias Hmede, or Samir.
5. Click **Submit**. The task appears in the TODO column with the employee's colour-coded name tag.

## Moving a task

Drag any task card and drop it onto a different column to change its status.
The new status is saved automatically and will still be there after a refresh.

## Filtering by employee

Use the **Filter** dropdown at the top to show only one employee's tasks.
Select **All** to see every task again.
Filtering does not change or delete any data.

## Deleting a task

Click the **x** button on a task card to delete it.
The deletion is saved immediately.

## Data storage

All tasks are stored in your browser's localStorage.
Clearing your browser data will erase the board.
The board is not shared in real time across different devices or browsers.
